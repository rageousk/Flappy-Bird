# Flappy-Bird
This is my final gaming Project Flappy-Bird for Unity/C# course.
Here in this game I combined the functionality of Mario game, Piranhas pops-up from Pipes at regular intervals.
In this game, Bird has an ability to shoot down those Piranhas using arrow, when "F" key is pressed.
I really enjoyed this project, there is a lot more can be done in it.
